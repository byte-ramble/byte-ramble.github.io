产品

WTP 标准是核心入口；Google 交易解析插件排第二，后续承接链上监测、交易仿真与 Token 风险分析。

核心标准

WTP 钱包交易构造溯源标准

用交易字节、目标链与来源证明交叉校验签名前内容，降低盲签、前端篡改和来源伪造风险。

  • 校验交易字节与 intent hash
  • 确认目标链、合约和关键参数
  • 验证钱包厂商来源证明
查看 WTP 介绍
Google Chrome 插件

Google 交易解析插件

在 Google Chrome 中解析交易请求、授权目标、合约调用与关键风险字段。

  • 解析交易请求与合约调用
  • 展示授权对象、目标地址与关键参数
  • 辅助识别盲签、误签与异常调用
安装 Chrome 插件
链上监测

ChainWatch

为关键地址、合约权限、资金路径与协议事件建立实时监测。

  • 地址与合约事件订阅
  • 规则引擎与分级告警
  • ABI、权限与地址上下文补全
交易仿真

RiskLens

在执行前解析交易意图、仿真资产变化，并输出可读风险结论。

  • 交易解码与意图识别
  • 执行前仿真与风险评分
  • 异常模式与路径识别
Token 风险分析

MintGuard

聚焦 owner 权限、流动性、持仓结构与退出风险，支持 Token 准入前评估。

  • 权限与 owner 风险
  • 流动性健康度监测
  • 持仓与筹码结构分析
